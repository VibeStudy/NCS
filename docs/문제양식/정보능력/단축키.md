## 사용 목적

* 이 문서는 복습할 때 단축키 문제를 이미지 속 기출 양식처럼 만들어 달라고 요청하기 위한 참고 문서이다.

* 문제를 만들 때는 단순 암기 확인보다 단축키와 기능을 바르게 연결하는 능력을 확인하도록 출제한다.

* 문제에는 정답이 바로 드러나지 않도록 비슷한 기능의 단축키를 오답으로 섞는다.

* 문제 출제 범위는 `docs/개념/전략과목/정보능력.md`의 `프로그램 활용` 단원 중 단축키 관련 내용을 기준으로 한다.

## 공통 출제 규칙

* 문제 문장
    * NCS 정보능력 지문처럼 업무 상황을 짧게 제시한다.
    * 신입사원, 업무 효율성, 발표 준비, 교육자료, 파일 정리, 프로그램 활용 같은 상황을 사용한다.
    * 발문 끝에는 `바르게 연결되지 않은 것은?`, `잘못된 부분은 모두 몇 개인가?`, `옳은 것은 모두 몇 개인가?`처럼 묻는다.

* 보기 구성
    * 보기에는 단축키와 기능 설명을 함께 쓴다.
    * 보기는 5개 또는 10개로 만든다.
    * 개수 세기 문제는 보기 8~10개로 만든다.
    * 단축키 표기는 `Ctrl + C`, `Alt + F4`, `Windows + D`, `Shift + F5` 형식으로 통일한다.

* 오답 구성
    * 비슷한 기능의 단축키를 바꾸어 오답을 만든다.
    * 예: Ctrl + Alt + Del과 Ctrl + Shift + Esc를 서로 헷갈리게 만든다.
    * 예: F2와 F3을 서로 헷갈리게 만든다.
    * 예: F5와 Shift + F5를 서로 헷갈리게 만든다.
    * 예: Ctrl + V와 Ctrl + Z를 서로 헷갈리게 만든다.

* 출력 형식
    * 먼저 문제만 제시한다.
    * 사용자가 답을 말하기 전에는 정답과 해설을 숨긴다.
    * 사용자가 답을 제출하면 정답, 오답 판단 근거, 암기 포인트를 제시한다.

## Windows 단축키

### 연결 오류 찾기

* 출제 의도
    * Windows에서 자주 사용되는 바로가기 키와 기능의 연결이 맞는지 확인한다.

* 발문 예시
    * 다음은 윈도우에서 자주 사용되는 바로가기 키와 그 기능을 연결한 내용이다. 바르게 연결되지 않은 것은?

* 보기 예시
    * Alt + F4: 창 닫기, 프로그램 종료

    * Alt + Tab: 활성화된 프로그램 창 전환

    * Ctrl + Alt + Del: 작업관리자 실행

    * Ctrl + Z: 실행 취소

    * Windows + D: 바탕화면 이동

* 정답 설계
    * 정답은 1개로 만든다.
    * 정답 보기에는 실제 기능과 비슷하지만 엄밀히 틀린 설명을 붙인다.

* 자주 쓰는 오답 포인트
    * Ctrl + Alt + Del: 작업관리자 실행이라고 쓰면 오답이다.
    * Ctrl + Alt + Del은 보안 옵션 화면 표시이다.
    * 작업관리자 바로 실행은 Ctrl + Shift + Esc이다.

    * Alt + Esc: 시작 메뉴 열기라고 쓰면 오답이다.
    * Alt + Esc는 실행 중인 프로그램 창을 순서대로 전환한다.
    * 시작 메뉴 열기는 Ctrl + Esc 또는 Windows 키이다.

    * F2: 파일 또는 폴더 검색이라고 쓰면 오답이다.
    * F2는 이름 변경이다.
    * 파일 또는 폴더 검색은 F3이다.

### 옳은 설명 개수 세기

* 출제 의도
    * 여러 단축키 설명 중 맞는 것과 틀린 것을 모두 구분하게 한다.

* 발문 예시
    * 신입사원 직무능력 교육자료를 준비 중이다. 다음은 업무 중 Windows 단축키를 정리한 자료이다. 옳은 설명은 모두 몇 개인가?

* 보기 예시
    * Alt + F4: 열려 있는 창을 종료한다.

    * Alt + Esc: 시작 메뉴를 연다.

    * Ctrl + Delete: 선택 항목을 삭제하고 휴지통으로 이동한다.

    * Ctrl + Shift + Esc: 작업관리자를 실행한다.

    * Ctrl + C: 선택한 항목을 복사한다.

    * Ctrl + V: 작업 실행을 취소한다.

    * Windows + L: PC를 잠그거나 사용자 계정을 전환한다.

    * Windows + Tab: 열린 모든 창을 표시하고 가상 데스크톱으로 바로 간다.

    * F2: 파일 탐색기에서 파일 또는 폴더를 검색한다.

    * F5: 활성화된 창을 새로 고친다.

* 정답 설계
    * 보기 10개 중 4~7개가 맞도록 만든다.
    * 정답 선택지는 `2개`, `3개`, `4개`, `5개`, `6개`, `7개`처럼 개수로 제시한다.
    * 개수 선택지는 정답 전후 숫자를 포함해 헷갈리게 만든다.

* 자주 쓰는 정답 포인트
    * Alt + F4: 열려 있는 창 종료는 옳다.
    * Ctrl + Shift + Esc: 작업관리자 실행은 옳다.
    * Ctrl + C: 복사는 옳다.
    * Windows + L: PC 잠금 또는 사용자 계정 전환은 옳다.
    * Windows + Tab: 열린 창 보기 및 가상 데스크톱 이동은 옳다.
    * F5: 새로 고침은 옳다.

* 자주 쓰는 오답 포인트
    * Alt + Esc: 시작 메뉴 열기는 틀리다.
    * Ctrl + Delete: 선택 항목 삭제 후 휴지통 이동은 틀리다.
    * Ctrl + V: 작업 실행 취소는 틀리다.
    * F2: 파일 또는 폴더 검색은 틀리다.

## 파워포인트 단축키

### 잘못된 단축키 찾기

* 출제 의도
    * 발표 상황에서 자주 쓰는 파워포인트 단축키를 기능과 연결하게 한다.

* 발문 예시
    * 김영 씨는 파워포인트를 이용해서 발표할 때 여러 기능을 많이 느낀다. 업무효율성을 향상시키기 위해 파워포인트 단축키를 확인 중이다. 다음 중 잘못된 부분은 어떤 것인가?

* 보기 예시
    * Ctrl + W: 프레젠테이션 닫기

    * Ctrl + F1: 리본 메뉴 숨기기

    * Ctrl + Shift + F1: 전체화면 보기

    * Shift + F5: 첫 번째 슬라이드부터 슬라이드 쇼 시작하기

    * Alt + F5: 발표자 보기 전환하기

    * Ctrl + F5: 현재 창 닫기

* 정답 설계
    * 정답은 1개 또는 2개로 만든다.
    * 선택지는 `ㄱ`, `ㄴ`, `ㄷ`, `ㄹ`, `ㅁ`, `ㅂ`처럼 기호로 표시해도 좋다.
    * 최종 선택지는 `① ㄱ, ㄴ`, `② ㄱ, ㄷ`, `③ ㄷ, ㅂ`, `④ ㄹ, ㅂ`, `⑤ ㄹ, ㅁ`처럼 묶음으로 제시한다.

* 자주 쓰는 오답 포인트
    * Shift + F5: 첫 번째 슬라이드부터 슬라이드 쇼 시작하기는 틀리다.
    * Shift + F5는 현재 슬라이드부터 슬라이드 쇼 시작이다.
    * 첫 번째 슬라이드부터 슬라이드 쇼 시작은 F5이다.

    * Ctrl + F5: 현재 창 닫기는 틀리다.
    * 현재 창 닫기는 Ctrl + F4이다.

* 자주 쓰는 정답 포인트
    * Ctrl + W: 현재 프레젠테이션 닫기는 옳다.
    * Ctrl + F1: 리본 메뉴 표시 또는 숨기기는 옳다.
    * Alt + F5: 발표자 보기로 슬라이드 쇼 시작은 옳다.

## 정답 및 해설 작성 규칙

* 사용자가 답을 제출하기 전
    * 정답과 해설을 보여주지 않는다.
    * 문제와 보기만 제시한다.

* 사용자가 답을 제출한 뒤
    * 정답 여부를 먼저 말한다.
    * 틀린 보기마다 실제 기능을 짧게 고쳐 쓴다.
    * 마지막에 암기 포인트를 2~4개로 정리한다.

* 해설 예시
    * Ctrl + Alt + Del은 작업관리자 바로 실행이 아니라 보안 옵션 화면 표시이다.
    * 작업관리자 바로 실행은 Ctrl + Shift + Esc이다.
    * F2는 이름 변경, F3은 검색이다.
    * F5는 처음부터 슬라이드 쇼, Shift + F5는 현재 슬라이드부터 슬라이드 쇼이다.
