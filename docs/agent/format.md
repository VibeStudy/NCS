# 문서 작성 규칙

`docs/개념/**/*.md`, `노트/*.md` 파일은 개념 정리용 문서다. 기존 문서의 목차와 제목 구조를 기준으로 작성한다.

문서 수정 전에는 이 문서를 먼저 확인하고, 제목 추가/수정/삭제/이동 여부를 판단한다.

## 기본 구조

```markdown
# 문서 제목

## 목차

- [대분류](#대분류)
  - [중분류](#중분류)

---

## 대분류

### 중분류

* 핵심 설명
* 추가 설명
```

## 제목 규칙

- 문서 제목은 `#` 1개 사용
- 목차 제목은 `## 목차` 사용
- 큰 단원은 `##` 사용
- 세부 개념은 `###` 사용
- 큰 단원(`##`) 제목에는 하위 세부 개념(`###`) 개수를 `단원명(n)` 형식으로 표시
- 세부 개념(`###`) 제목에는 사용자가 요청했거나, 항목 수를 제목에서 바로 확인하는 것이 유용한 경우에만 하위 항목 개수를 `세부 개념명(n)` 형식으로 표시
- 세부 개념(`###`)의 하위 항목 개수 표시는 모든 `###`에 일괄 적용하지 않고, 과정의 개수·유형의 개수처럼 숫자로 세기 적합한 항목에 적용
- 목록형·분류형·유형형·과정형·특성형처럼 개수 확인이 학습에 도움이 되는 곳은 `인적자원관리의 중요성(2)`, `인적자원 관리 원칙(8)`, `인맥의 정의(3)`, `인맥관리 방법(3)`, `인력 배치의 유형(3)`처럼 표시
- `####` 이하 소분류는 사용하지 않음
- 섹션 분리 요청을 받으면 새 제목은 `###`로 만들고 목차에 추가
- `###` 아래에서 더 나누어야 하는 내용은 제목 대신 `* 개념명` 목록으로 분리
- 제목 끝에 불필요한 공백을 넣지 않음

## 목차 규칙

- 문서 상단에 목차를 둠
- 목차는 실제 제목 순서와 같게 작성
- `##`, `###`까지만 목차에 포함
- 큰 단원(`##`) 제목에 표시한 하위 세부 개념 개수는 목차에도 동일하게 반영
- 세부 개념(`###`) 제목에 하위 항목 개수를 표시한 경우 목차에도 동일하게 반영
- 목차와 본문 사이에는 `---` 구분선 삽입
- 제목을 바꾸거나 이동하면 목차 링크도 같이 수정
- 문서를 변경할 때 제목을 추가/수정/삭제/이동하면 목차도 같이 수정

## 본문 규칙

- 본문 설명은 `*` 목록 사용
- 한 항목에는 한 개념만 작성
- 개념은 `* 개념명`으로 먼저 작성하고, 설명은 들여쓰기한 하위 목록으로 작성
- 개념 목록 항목에는 사용자가 요청했거나, 하위 항목 수를 바로 확인하는 것이 유용한 경우에만 `* 개념명(n)` 형식으로 표시
- 개념 목록 항목의 하위 항목 개수 표시는 모든 목록에 일괄 적용하지 않고, 과정의 개수·유형의 개수처럼 숫자로 세기 적합한 항목에 적용
- 묶음형·분류형·유형형·과정형·암기형 목록처럼 개수 확인이 학습에 도움이 되는 곳은 `* 개념명(n)` 형식으로 표시
- 같은 들여쓰기 레벨의 목록 항목 사이에는 빈 줄 하나를 추가
- 짧은 정의만 필요한 경우에만 `* 개념명: 설명` 형식 사용 가능
- 훈련 방법, 행동 요령, 암기 항목처럼 짧게 나열하는 내용은 명사형으로 통일 가능
- 약어는 처음 작성할 때 풀어쓴 명칭을 함께 작성
- 약어 표기는 `약어; 풀어쓴 명칭` 형식 사용
- 본문, 목록, 표에서 볼드 처리(`**굵게**`) 금지
- 암기 순서는 `A → B → C` 형식 사용
- 사용자 요청이 없으면 비교나 분류가 많아도 표를 사용하지 않고 목록으로 작성
- 간단한 보충 설명은 인용문(`>`) 사용
- 여러 문서에서 반복되는 개념 항목은 다음 순서로 작성
  - 의미
  - 필요성
  - 특징
  - 구성요소
  - 기능
  - 분류
  - 유형
  - 과정

## 표 규칙

- 사용자 요청이 없으면 표 사용 금지
- 사용자가 표 작성을 요청한 경우에만 표 사용 가능
- 비교, 분류, 구성 요소 정리는 기본적으로 목록으로 작성

## 코드블록 규칙

- 흐름도, 절차, 명령, 코드 예시는 코드블록 사용
- 언어가 명확하면 코드블록에 언어명 표시
- 단순 흐름도는 언어명 없이 작성 가능

## 구분선 규칙

- 큰 단원(`##`) 사이에는 필요하면 `---` 사용
- 같은 단원 안에서 너무 자주 사용하지 않음
- 목차와 본문 사이에는 반드시 `---` 사용
