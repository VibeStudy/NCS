## 자원의 개념 및 관리 과정(3)

### 자원의 개념(4)

* 시간
  * 설명: 업무 수행에 사용 가능한 시간

* 예산
  * 설명: 업무에 투입되는 비용·자금

* 물적자원
  * 설명: 장비, 시설, 재료 등 물리적 자원

* 인적자원
  * 설명: 업무를 수행하는 사람(인력, 역량)

---

### 자원의 낭비요인(4)

* 비계획적 행동
  * 설명: 계획 없이 즉흥적으로 행동하여 자원을 낭비

* 편리성 추구
  * 설명: 당장 편한 방법을 선택해 비효율 발생

* 자원에 대한 인식 부재
  * 설명: 자원의 유한성을 인식하지 못해 무분별하게 사용

* 노하우 부족
  * 설명: 효율적인 자원 활용 방법을 몰라 낭비 발생

---

### 효과적인 자원관리 과정(4)

* 1단계: 필요한 자원 확인
  * 내용: 업무 목표 달성에 어떤 자원이 얼마나 필요한지 파악

* 2단계: 이용 가능한 자원 수집
  * 내용: 실제로 확보 가능한 자원의 종류·양을 조사

* 3단계: 자원 활용 계획 수립
  * 내용: 수집된 자원을 어떻게 배분·사용할지 계획 작성

* 4단계: 계획에 따른 수행
  * 내용: 계획대로 자원을 투입하고 실행

## 시간자원관리(7)

### 시간의 특성(6)

- 매일 24시간
- 속도가 일정
- 멈출 수 없음
- 빌리거나 저축할 수 없음
- 사용 방법에 따라 가치가 다름
- 시기에 따라 밀도가 다름

---

### 시간 관리의 효과(2)

**개인 관점**
- 생산성 향상
- 스트레스 감소
- 균형적인 삶 
- 목표 성취

**기업 관점**
- 생산성 향상 
- 가격 인상 
- 위험 감소 
- 시장점유율 증가

---

### 시간 낭비 요인(2)

* 내부적 요인
  * 예시: 우선순위 미설정, 미루는 습관, 충동적 행동

* 외부적 요인
  * 예시: 불필요한 회의, 잦은 방문객·전화, 예상치 못한 업무

---

### 시간계획 방법(4)

1. 목표 설정(SMART)
2. 우선순위 결정(시간 매트릭스)
3. 소요시간 결정
4. 계획서 작성

* SMART 법칙
  * S; Specific: 목표를 명확하고 구체적으로 설정
  * M; Measurable: 달성 여부를 수치로 확인 가능해야 함
  * A; Action-oriented: 구체적인 행동으로 실천할 수 있는 목표여야 함
  * R; Realistic: 자신의 상황·자원에 맞는 목표여야 함
  * T; Time-bound: 목표 달성 기한을 명확히 정해야 함

* 시간 매트릭스
  * 중요하고 긴급함: 1사분면, 즉시 처리
  * 중요하고 긴급하지 않음: 2사분면, 계획적으로 처리
  * 중요하지 않고 긴급함: 3사분면, 위임 가능
  * 중요하지 않고 긴급하지 않음: 4사분면, 제거·최소화

> 시간관리의 핵심은 2사분면(중요하지만 긴급하지 않은 일)에 충분한 시간을 투자하는 것이다.

---

### 시간계획 고려사항(5)

* 분석과 목록화(2)
  * 어디에 어떻게 시간을 사용하는지 행동, 시간, 시간관리 저해요인을 분석

  * 해당 시간에 예정된 일과 행동을 모두 리스트화

* 시간 확보(4)
  * 예정된 행동 외에 기대되는 성과와 행동의 목표도 기록

  * 예상치 못한 일, 이동시간, 대기시간 같은 자유시간을 고려하여 여유시간 확보

  * 전체적인 계획을 정리하는 시간 확보

  * 본인 이외의 사람들의 시간계획도 감안

* 현실적 계획(3)
  * 실현 가능한 것만 현실적으로 계획

  * 목표 달성을 위한 계획임을 알고 유연성 있게 수립

  * 적절한 시간 프레임(Frame)을 설정하고 필요한 시간만 계획에 포함

* 실행과 점검(4)
  * 시간계획을 규칙적·체계적으로 체크하여 일관성 있게 마무리

  * 체크리스트나 스케줄 표로 전체 상황을 파악

  * 해야 할 일을 끝내지 못했을 경우 차기 계획에 반영

  * 시간 손실이 발생하면 미루지 않고 바로 보상

* 우선순위와 위임(3)
  * 일의 경중에 따라 시간을 할애
    * 예시: 야근을 해서라도 긴급한 일을 끝내는 것은 적절한 시간계획에 해당함

  * 우선순위를 고려하여 먼저 처리할 일을 결정

  * 자신의 업무 일부를 부하에게 위임하고 수행 책임을 지도록 하는 권한위양 실행

> 권한위양은 조직을 탄력적으로 운용하고 조직구성원들의 근로의욕을 높여주는 데 효과적임

---

### 부적절한 시간계획 방식(2)

* 지나치게 세밀하게 계획함
  * 최대한 많은 업무를 수행하기 위해 1분 단위로 계획함

* 모든 일 수행
  * 팀원들보다 업무 능력이 뛰어나다고 판단하여 모든 일을 혼자 수행함
  * 위임을 하지 않아 부적절

---

### 60:20:20 법칙(3)

* 계획된 행동
  * 비율: 60%
  * 설명: 예정된 업무·일정

* 자발적 행동
  * 비율: 20%
  * 설명: 창조성 발휘

* 계획 외의 행동
  * 비율: 20%
  * 설명: 돌발 상황 대비 여유

## 예산자원관리(9)

### 예산의 정의(2)

- **사전적 의미:** 필요한 비용을 미리 헤아려 계산함
- **넓은 의미:** 개인 및 조직의 수입과 지출에 관한 것도 포함

### 예산관리능력의 정의

이용 가능한 예산을 확인하고 어떻게 사용할 것인지 계획하여 계획대로 사용하는 능력.
최소의 비용으로 최대의 효과를 얻기 위해 필요함.

---

### 책정 비용과 실제 비용의 균형(3)

* 책정 비용 > 실제 비용
  * 결과: 경쟁력 손실

* 책정 비용 < 실제 비용
  * 결과: 적자 발생

* 책정 비용 = 실제 비용
  * 결과: 이상적

---

### 예산관리의 구성

예산관리에는 비용 산정, 예산 편성뿐만 아니라 예산을 통제하는 것까지 포함됨.

---

### 예산의 구성요소(2)

* 직접비용
  * 설명: 제품·서비스 창출에 직접 소비된 비용
  * 예시: 재료비, 원료·장비, 시설, 인건비, 출장비

* 간접비용
  * 설명: 생산에 간접적으로 소비된 비용
  * 예시: 보험료, 건물관리비, 광고비, 통신비, 공과금

---

### 예산수립 과정(3)

1. 필요한 과업 및 활동 구명
  * 내용: 예산 범위 내에서 수행해야 하는 활동과 소요예산을 정리

2. 우선순위 결정
  * 내용: 활동별 예산 지출 규모를 확인하고 우선순위를 확정

3. 예산 배정
  * 내용: 우선순위가 높은 활동부터 예산을 배정하고 사용

> - 확보 순서: 고정비 → 유동비 → 예비비
> - 삭감 순서: 유동비 → 예비비 → 고정비

### 과업세부도 (WBS)

- 과제 및 활동계획 수립 시 가장 기본적인 수단으로 활용되는 그래프
- 모든 일을 중요한 범주에 따라 체계화해 구분하며, 구체성에 따라 2단계, 3단계, 4단계 등으로 구분 가능

| 1단계 | 2단계 | 3단계 | 4단계 |
|-------|-------|-------|-------|
| 생일파티 | 계획 | | |
| | 음식 준비 | | |
| | 각종 기구 | | |
| | 세팅 | 게임과 오락 | 배구 네트 설치 |
| | | | 수영장 청소 |
| | | 청소 | 집안 청소 |
| | | | 잔디 깎기 |
| | | 도구 | 테이블과 의자 설치 |
| | | | 텐트 설치 |
| | 파티 후 청소 | | |

### 예산수립 시 주의사항

- 큰 단위의 예산을 수립할 경우 기관의 규정을 확인하여 반영해야 함

---

### 예산집행 관리(2)

* 예산집행 관리 방법
  * 업무적 차원
    * 방법: 예산집행 실적을 워크시트로 작성

  * 개인적 차원
    * 방법: 수기 또는 프로그램·앱을 활용하여 가계부 작성

* 예산집행 시 주의사항
  * 예산계획에 차질이 없도록 예산집행 내역과 계획을 지속적으로 비교·검토해야 함

## 물적자원관리(6)

### 물적자원의 개념

인간이 약한 신체적 특성을 보완하기 위하여 사용하는 자원으로, 세상에 존재하는 모든 물체가 포함됨.

### 물적자원관리의 중요성(2)

- 효과적으로 관리할 경우 → 과제·사업의 성공으로 경쟁력 향상
- 관리가 부족할 경우 → 과제·사업 실패, 경제적 손실 발생

### 물적자원의 종류(2)

* 자연자원
  * 설명: 자연 상태에 있는 그대로의 자원

  * 예시: 석유, 석탄, 나무

* 인공자원
  * 설명: 인간이 인위적으로 가공하여 만든 자원

  * 예시: 시설, 장비

---

### 물적자원관리 절차(3)

* 사용 물품과 보관 물품의 구분
  * 내용: 활용 계획을 철저히 확인하여 꺼냈다가 다시 넣는 반복 작업을 방지하고 편리성을 높임

* 동일 및 유사 물품으로의 분류
  * 내용: 동일성의 원칙(같은 품종은 같은 장소)·유사성의 원칙(유사품은 인접 장소)에 따라 보관

* 물품 특성에 맞는 보관 장소 선정
  * 내용: 재질, 무게, 부피 등 물품 특성을 반영하여 보관 장소를 선정

### 회전대응 보관의 원칙(2)

① 입·출하의 빈도가 높은 품목은 출입구에서 가까운 곳에 보관
② 물품의 활용 빈도가 상대적으로 높은 것은 가져다 쓰기 쉬운 위치에 보관

## 인적자원관리(8)

### 인적자원관리의 의미

목적을 달성하기 위하여 필요한 인적자원을 조달·확보·유지·개발하여 경영 조직 내 구성원의 능력을 최고로 발휘하도록 하며, 근로자와 사용자 간의 협력 체계가 이루어지도록 관리하는 것.

### 인적자원의 필요성

사업의 발달로 생산 현장이 첨단화·자동화되었으나, 물적자원과 예산 등의 생산요소를 효율적으로 결합시켜 가치를 창조하는 일은 사람이 하므로 기업 경영에서는 구성원의 자발적인 협력이 필요함.

### 인적자원관리의 중요성(2)

* 기업적 차원
  * 의미: 조직의 성과는 인적자원에 대한 관리의 영향을 크게 받으며, 이는 인적자원의 특성에서 비롯됨

  * 능동성
    * 설명: 예산·물적자원과 달리 능동적·반응적 성격을 지님. 성과는 욕구·동기·태도·만족감에 따라 달라지며 경영관리에 의해 조건화됨

  * 개발가능성
    * 설명: 자연적 성장과 성숙은 물론, 오랜 기간에 걸쳐 개발될 수 있는 잠재능력과 자질을 보유함

  * 전략적 자원
    * 설명: 다양한 자원을 활용하는 것은 결국 사람이므로 다른 어떤 자원보다도 전략적 중요성이 강조됨

* 개인적 차원
  * 각종 정보와 정보의 소스를 획득할 수 있음

  * 나 자신의 인간관계와 행동에 대해서 알 수 있으며, 삶의 탄력을 얻을 수 있음

  * 참신한 아이디어나 도움을 얻을 수 있음

### 인적자원 관리 원칙(8)

* 적재적소 배치의 원칙
  * 의미: 팀원의 능력·성격과 가장 적합한 위치에 배치하여 개개인의 능력을 최대로 발휘하도록 함
  * 영어 표현: The right man for the right job

* 공정 보상의 원칙
  * 의미: 성과와 기여도에 따라 공정하게 보상함

* 공정 인사의 원칙
  * 의미: 인사 과정에서 공정성과 객관성을 유지함

* 종업원 안정의 원칙
  * 의미: 구성원이 안정적으로 일할 수 있는 근무 여건을 마련함

* 창의력 계발의 원칙
  * 의미: 구성원의 창의성과 잠재 능력을 개발할 수 있도록 지원함

* 단결의 원칙
  * 의미: 구성원 간 협력과 단결을 높여 조직 목표 달성을 돕도록 함

* 능력주의
  * 의미: 능력을 발휘할 기회와 장소를 부여하고, 성과를 바르게 평가하며 능력·실적에 상응하는 보상을 줌

* 균형주의
  * 의미: 전체와 개체가 균형을 이룰 수 있도록 모든 팀원에 대해 평등한 적재적소를 고려함

### 인맥의 정의(3)

* 인맥
  * 의미: 가족, 친구, 직장동료 등 자신이 알고 있거나 관계를 형성하고 있는 다양한 사람들

* 핵심 인맥
  * 설명: 자신과 직접적인 관계가 있는 사람들

* 파생 인맥
  * 설명: 핵심 인맥을 통해 알게 된 사람, 우연히 알게 된 사람 등

### 인맥관리 방법(3)

* 명함관리
  * 받은 명함을 인맥관리에 적극적으로 사용

  * 명함관리 프로그램·애플리케이션 활용

  * 명함에 상대에 대한 구체적인 정보를 메모

* 인맥관리카드 작성
  * 이름, 관계, 직장·부서, 학력, 출신지, 연락처, 친한 정도 등을 정리하여 관리

  * 핵심·파생 인맥을 구분하여 작성하며, 파생 인맥 카드에는 어떤 관계에 의해 파생되었는지 포함

* 소셜네트워크
  * SNS; Social Network Service: 시간과 공간을 초월하여 네트워크상에서 인맥을 형성·관리

  * BNS; Business Social Network Service: 비즈니스 특화 서비스

  * 예시: 링크드인(LinkedIn)

### 인력 배치의 유형(3)

* 양적 배치
  * 의미: 작업량과 조업도, 여유·부족 인원을 감안하여 소요 인원을 결정·배치

* 질적 배치
  * 의미: 능력이나 성격 등과 가장 적합한 위치에 배치
  * 관련 개념: 적재적소의 배치

* 적성 배치
  * 의미: 팀원의 적성 및 흥미에 따라 배치

> 양적·질적·적성 배치는 따로 분리되는 것이 아닌 적절히 조화하여 운영되어야 함

### 과업세부도

* 의미
  * 인력을 배치하여 업무를 수행하는 과정에서 팀원들에게 할당된 일을 적절히 관리하기 위해 작성하는 도구

* 필요성
  * 팀원별 업무 분담과 진행 상황을 체계적으로 관리하는 데 효과적임

## 문제 유형(9)

### 인원 배분 프로젝트 일정

* 유형
  * 정해진 총인원을 여러 프로젝트에 배분하여 전체 프로젝트의 진행 순서와 완료 시점을 판단하는 문제다.

* 조건
  * 각 프로젝트는 필요한 인원이 정확히 배정되어야 시작할 수 있다.

  * 필요한 인원이 부족하면 일부 인원만 투입해서 진행할 수 없다.

* 풀이 방향
  * 필요한 인원이 많은 프로젝트부터 진행한다.

  * 남은 인원으로 시작 가능한 프로젝트를 다시 찾는다.

  * 필요한 인원이 같으면 기간이 긴 프로젝트부터 진행한다.

  * 프로젝트가 끝나면 인원을 회수한 뒤 같은 기준으로 반복한다.

* 핵심
  * 인원 제약 때문에 나중에 시작하기 어려운 프로젝트를 먼저 배치한다.

* 예시 조건
  * 총인원: 8명

  * A 프로젝트: 5명, 3일

  * B 프로젝트: 3명, 5일

  * C 프로젝트: 3명, 2일

  * D 프로젝트: 2명, 4일

* 풀이 예시
  | 구분 | 1일차 | 2일차 | 3일차 | 4일차 | 5일차 | 6일차 | 7일차 |
  |------|-------|-------|-------|-------|-------|-------|-------|
  | A 프로젝트 | 진행 | 진행 | 진행 | - | - | - | - |
  | B 프로젝트 | 진행 | 진행 | 진행 | 진행 | 진행 | - | - |
  | C 프로젝트 | - | - | - | 진행 | 진행 | - | - |
  | D 프로젝트 | - | - | - | 진행 | 진행 | 진행 | 진행 |
  | 사용 인원 | 8명 | 8명 | 8명 | 8명 | 8명 | 2명 | 2명 |
  | 남은 인원 | 0명 | 0명 | 0명 | 0명 | 0명 | 6명 | 6명 |

### 일정 소요시간 계산

* 풀이 방향
  * 일정이 길게 주어지지 않는 경우 테이블을 만들어 슬롯을 배정하는 방식으로 풀이한다.

* 예시 조건
  * A: 2일, 선행 업무 없음
  * B: 1일, 선행 업무 없음
  * C: 2일, A 완료 후
  * D: 1일, B 완료 후
  * E: 1일, C와 D 완료 후

* 슬롯 배정

| 1일차 | 2일차 | 3일차 | 4일차 | 5일차 |
|-------|-------|-------|-------|-------|
| A | A | C | C | E |
| B | D | - | - | - |

* 계산

| 경로 | 소요일 | 판단 |
|------|--------|------|
| A → C → E | 2일 + 2일 + 1일 = 5일 | 임계 경로 |
| B → D | 1일 + 1일 = 2일 | E를 대기 |

* 정답: 5일

* 핵심
  * 최소 완료일은 임계 경로를 기준으로 판단한다.

### 시차 계산

* 풀이 방향
  * 행에는 이벤트를 두고, 열에는 국가별 시간을 두는 방식으로 정리한다.
  * UTC 기준점을 먼저 구한 뒤 각 시간대에 더하거나 빼면 실수를 줄일 수 있다.

* 예시 조건
  * 서울(UTC+9) 기준 3월 1일 오전 10:00 회의 시작
  * 회의 시간 1시간
  * 런던 UTC+0
  * 뉴욕 UTC-5

* 계산

| 변환 | 계산 | 결과 |
|------|------|------|
| 서울 → UTC | 3/1 10:00 - 9시간 | 3/1 01:00 |
| UTC → 런던 | 3/1 01:00 + 0시간 | 3/1 01:00 |
| UTC → 뉴욕 | 3/1 01:00 - 5시간 | 2/28 20:00 |

* 결과

| 이벤트 | 서울(UTC+9) | 런던(UTC+0) | 뉴욕(UTC-5) |
|--------|-------------|-------------|-------------|
| 회의 시작 | 3/1 10:00 | 3/1 01:00 | 2/28 20:00 |
| 회의 종료 | 3/1 11:00 | 3/1 02:00 | 2/28 21:00 |

* 핵심
  * 시차 계산에서는 날짜가 전날 또는 다음 날로 바뀌는지 확인한다.

### 순차 공정 파이프라인

* 유형
  * 제품 1개가 A → B → C → D 공정을 순서대로 거치는 방식에서 N개 완료 최소 시간을 구하는 문제다.

* 공식
  * 최소 시간 = 전체 공정 합 + 병목 공정 × (N - 1)

* 예시 조건
  * A: 2분
  * B: 3분
  * C: 4분
  * D: 6분
  * 제품 수: 30개

* 계산
  * 첫 번째 제품 완성 시간 = 전체 공정 합 = 2 + 3 + 4 + 6 = 15분
  * 병목 공정 = 가장 오래 걸리는 D = 6분
  * 최소 시간 = 15 + 6 × (30 - 1) = 189분

* 핵심
  * 첫 제품이 나온 이후에는 병목 공정 주기마다 1개씩 완성된다.
  * 전체 합이나 평균이 아니라 가장 느린 공정이 처리 속도를 결정한다.

### 경로 문제

* 재방문하지 않고 순회하는 경우 
  * 간선이 2개인 노드(차수 2)는 경로가 강제된다.
  * 순회하려면 최소 2개의 간선이 필요하다.
  * 따라서 간선이 2개인 쪽의 노드는 2개 간선을 모두 써야 한다.

### 점수 계산

* 유형
  * 지름길 없이 조건대로 모두 계산해야 하는 유형이다.

* 풀이 방법
  * 평가 항목별 점수를 정리한 뒤 행마다 합산해서 비교한다.
  * 항목 수가 많을수록 먼저 구조를 잡고 열 단위로 채워나간다.

* 핵심
  * 계산 실수를 줄이려면 조건 반영 여부를 항목별로 확인한다.

### 매출액 계산

문제별 상이. 모든 문제의 핵심은 테이블을 잘 만드는 것

### 환전

* 풀이 방향
  * 환율 단위와 적용 방향을 먼저 확인한다.
  * 외화로 바꿀 때와 원화로 바꿀 때의 곱셈·나눗셈 방향을 구분한다.
  * 수수료나 우대율 조건이 있으면 환율을 먼저 조정한 뒤 계산한다.
