# NCS 문제 생성

문제 파일의 기존 출제 형식과 참조 노트의 개념만 사용해 NCS 연습문제를 작성한다.

공통 문항 양식은 저장소 `docs/problem-format.md`를 단일 기준으로 삼는다.

## 작업 순서

1. 파일 수정 전 저장소 `AGENTS.md`를 읽는다.
2. `docs/format.md`, `docs/problem-format.md`를 읽는다.
3. 대상 문제 파일 전체와 사용자가 지정한 참조 노트의 관련 단원을 읽는다. 사용자가 노트를 지정하지 않았으면 문제 파일의 과목명과 연결된 `note/` 문서를 찾아 관련 단원만 읽는다.
4. 기존 문제의 지문 구조, 선지 수, 정답 표기, 풀이 유무를 유지한다.
5. 요청한 정확한 문항 수만 추가한다. 기존 문항은 사용자가 요청하지 않으면 바꾸지 않는다.
6. 각 문항의 정답과 풀이를 노트의 근거 항목과 대조한다.

## 출제 원칙

* 참조 노트에 명시된 개념·업무·과정·분류만 정답 근거로 사용한다.
* 기존 문제의 출제 범위와 난이도를 유지하되, 지문·업무 조합·선지 순서·정답 번호는 변형한다.
* 각 보기의 소속 또는 옳고 그름을 하나씩 판정한 뒤 개수를 계산한다.
* 오답은 다른 단원 또는 다른 부서의 명확한 업무로 만든다. 애매하게 여러 부서가 수행할 수 있는 업무는 피한다.
* 정답 번호가 한 번호에 반복되지 않도록 가능한 범위에서 분산한다.
* 노트와 기존 문제의 정답이 충돌하면 노트를 우선한다. 충돌한 기존 문항은 임의 수정하지 말고 사용자에게 알린다.

## 문항 예제

````markdown
Q. 다음은 R사 영업부 사원의 일일업무일지이다. 업무 일지 내용 중 영업부의 주요 업무로 적절하지 않은 것은 모두 몇 개인가?

```
• 시장조사 실시 • 신규 거래처 개척
• 견적서 작성 및 계약 • 전사 소모품 관리
• 거래처 불만 처리 • 사원 공채 진행
• 제품 재고 조절 • 재무제표 분석 및 보고
```

① 1개 ② 2개 ③ 3개 ④ 4개 ⑤ 5개

정답: ③

풀이: 전사 소모품 관리는 총무부, 사원 공채 진행은 인사부, 재무제표 분석 및 보고는 회계부 업무이다. 나머지는 영업부 업무이므로 부적절한 업무는 3개이다.
````

## 검토

* 각 문항에서 정답에 해당하는 보기와 풀이의 개수가 일치하는지 확인한다.
* 모든 선지가 질문 조건(적절함, 부적절함, 개수)에 맞는지 다시 확인한다.
* `docs/problem-format.md`의 제목·문항 수·구분선·정답 형식을 검사한다.
