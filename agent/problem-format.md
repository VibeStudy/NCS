# 문제유형 문서 작성 규칙

`문제유형/**/*.md` 파일은 문제 풀이용 문서다. 개념 정리 문서와 별도 양식을 적용한다.

## 기본 구조

```markdown
# 문서 제목

## 단원명(문항 수)

Q. 문제

① 선지 ② 선지 ③ 선지 ④ 선지 ⑤ 선지

정답: ③
```

## 제목과 번호

* 문서 제목은 `#` 1개 사용

* 큰 단원은 `## 단원명(문항 수)` 형식 사용

* 문항 제목과 문항 번호는 사용하지 않음

* 단원에 문항을 추가하거나 삭제하면 단원명 뒤 문항 수도 함께 수정

* 사용자가 `N문항`을 요청하면 정확히 N개를 추가

## 문항 작성

* 문제는 `Q.`로 시작

* 선택지는 `①`부터 `⑤`까지 사용

* 보기 자료는 코드블록 안에 `<보기>`로 작성

* 선지 수, 단계 수, 의미 수처럼 개수가 핵심인 정보는 문제와 정답에 숫자로 명확히 표기

* 정답은 문항 끝에 `정답: 번호` 형식으로 표기

* 오답 선지를 포함한 문제는 문제에서 요구한 조건에 맞는지 정답 작성 전에 다시 검토

* 같은 유형의 문제를 추가할 때는 지문과 출제 범위를 유지하고 선지와 정답 번호를 바꿔 변형

* 연속 문항 사이에는 `---` 구분선 사용
