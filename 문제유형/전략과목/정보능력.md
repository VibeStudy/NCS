# 정보능력

## 정보 관리(5문항)

Q. 다음 사례에서 요리연구가 A가 사용한 방법으로 가장 적절한 것은? 

```
A씨는 요리 방법을 적은 문서를 분류하기로 하였고 이를 책으로 출판하였다. 책은 각 요리에서 주재료로 사용된 재료를 기준으로 요리 방법이 분류되었으며, 해당 재료에 대한 내용이 서울되어 있는 페이지로 같이 기술하였다. 
```

① 목록
② 목차
③ 분류
④ 초록
⑤ 색인

정답: ⑤ 색인

풀이: 재료명과 해당 내용이 있는 페이지를 함께 적은 것은 색인이다.

---

Q. 다음 사례에서 B사원이 사용한 정보 관리 방법으로 가장 적절한 것은?

```
B사원은 회의 자료에서 핵심 항목만 골라 항목별로 간단히 적은 목록을 만들었다. 이후 필요한 자료를 찾을 때는 해당 목록의 용어를 검색해 원문 파일을 확인하였다.
```

① 목록
② 목차
③ 분류
④ 초록
⑤ 색인

정답: ①

풀이: 중요한 항목을 찾아 정리하고 특정 용어로 검색할 수 있게 만든 것은 목록이다.

---

Q. 다음 사례에서 C사원이 작성한 정보 관리 방법으로 가장 적절한 것은?

```
C사원은 교육 자료의 장 제목과 각 장의 하위 항목을 순서대로 정리했다. 각 항목 옆에는 해당 내용이 시작되는 쪽 번호를 적어 전체 자료의 구조를 빠르게 파악할 수 있게 하였다.
```

① 목록
② 목차
③ 분류
④ 초록
⑤ 색인

정답: ②

풀이: 문서의 제목과 하위 항목을 순서대로 정리해 전체 구조와 위치를 확인하게 한 것은 목차이다.

---

```
D사원은 고객 문의 자료를 제품 유형, 문의 시기, 사용 목적에 따라 나누어 보관했다. 유사한 자료끼리 묶어 필요한 자료를 체계적으로 관리하려는 목적이다.
```

① 목록
② 목차
③ 분류
④ 초록
⑤ 색인

정답: ③

풀이: 유사한 정보를 기준에 따라 모아 체계적으로 정리한 것은 분류이다.

---

Q. 다음 사례에서 E사원이 작성한 정보 관리 방법으로 가장 적절한 것은?

```
E사원은 긴 조사 보고서를 읽기 전에 문서의 주제와 핵심 내용을 짧게 정리한 글을 먼저 작성했다. 독자가 전체 내용을 읽기 전에 보고서의 주요 내용을 빠르게 파악하게 하려는 목적이다.
```

① 목록
② 목차
③ 분류
④ 초록
⑤ 색인

정답: ④

풀이: 문서의 핵심 내용을 짧게 요약해 전체 내용을 읽기 전에 주제와 주요 내용을 파악하게 하는 것은 초록이다.
