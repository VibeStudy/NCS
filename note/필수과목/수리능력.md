## 응용 수리(6)

### 빠른 풀이

* 계산을 먼저 하기보다 전체 식을 먼저 세운다.
  * 식 전체를 보면 공통인수로 묶어 계산을 간단히 할 수 있다.
  * 예시: `0.6 × 0.03 × 0.9 + 0.4 × 0.09 × 0.9`
    * `0.9`를 공통인수로 묶기: `(0.6 × 0.03 + 0.4 × 0.09) × 0.9`
    * `0.018 + 0.036 = 0.054`이므로 `0.054 × 0.9 = 0.0486`


### 변수가 많은 문제

* 구하려는 변수를 기준으로 정리

  * A, B, C, D 중 A의 값을 구해야 한다면, B, C, D를 먼저 A에 관한 식으로 나타낸다.

  * 정리한 식을 나머지 조건에 대입하여 A만 남는 방정식을 세운다.

* 풀이 순서

  ```
  구하려는 변수 확인 → 다른 변수를 그 변수로 표현 → 나머지 조건에 대입 → 방정식 풀이
  ```

* 예시

  ```
  A의 값을 구하는 경우

  B = A - 3000
  C = 1.5A
  D = 0.5A + 4000

  합계 조건이 주어진다면:
  A + B + C + D = 합계
  → A + (A - 3000) + 1.5A + (0.5A + 4000) = 합계
  → 4A + 1000 = 합계
  → A = (합계 - 1000) ÷ 4
  ```

### 능률 문제

* 수식을 세우는 방법

  ```
  A 혼자서는 6시간이 걸린다.

  → x = 1/6

  A와 B가 함께는 3시간이 걸린다

  → x+y = 1/3. y = 1/6

  이 때 x는 A가 한 시간동안 처리하는 일의 양.
  y는 B가 한 시간동안 처리하는 일의 양을 의미한다.
  ```

* 계산하기 쉬운 수식으로 변환

  ```
  A는 2시간, B는 1시간 18분이 걸린다.

  → 시간을 분으로 변환
  → A는 1/120, B는 1/78
  ```

### 의자에 앉는 문제

* 변수: 의자 수

  ```
  의자에 6명씩 앉았을 때 10명이 남는다. (중략) 참석 인원은 몇 명인가?

  → 의자 수를 x, 참석 인원을 y로 둔다.
  → y = 6x + 10
  ```

* 마지막 의자에 앉은 인원이 주어지지 않은 경우는 부등식

  ```
  의자에 7명씩 앉았을 때 의자 1개가 남는다.

  마지막으로 사용한 의자에 앉은 인원이 주어지지 않았으므로 부등식을 세운다.

  7(x - 2) + 1 ≤ y ≤ 7(x - 2) + 7
  = 7x - 13 ≤ y ≤ 7x - 7

  빈 의자 1개와 마지막으로 사용한 의자 1개를 제외한 x - 2개 의자에는 각각 7명씩 앉는다.
  마지막으로 사용한 의자에는 1명 이상 7명 이하가 앉을 수 있다.
  ```

### 기초통계(2)

* 대표값(3)

  * 평균

    * 모든 자료의 합을 자료 수로 나눈 값

    ```
    평균 = 자료의 합 ÷ 자료 수
    ```

    * 모든 자료를 반영하지만, 극단값의 영향을 크게 받음

  * 중앙값

    * 자료를 크기순으로 정렬했을 때 가운데에 위치한 값

    ```
    홀수 개: 가운데 값
    짝수 개: 가운데 두 값의 평균
    ```

    * 극단값의 영향이 작음

  * 최빈값

    * 가장 자주 나타나는 값
    * 최빈값이 없거나 여러 개일 수 있음

* 산포도(2)

  * 분산

    * 자료가 평균에서 얼마나 퍼져 있는지 나타내는 값

    ```
    분산 = (각 자료와 평균의 차이를 제곱한 값의 합) ÷ 자료 수
    ```

    * 편차를 제곱하므로 항상 0 이상
    * 분산이 클수록 자료의 흩어진 정도가 큼

  * 표준편차

    * 분산의 양의 제곱근

    ```
    표준편차 = √분산
    ```

    * 원래 자료와 같은 단위를 사용하므로 분산보다 해석하기 쉬움
    * 표준편차가 작을수록 평균 주변에 자료가 모여 있음

### 원가와 정가의 구체적인 값이 없는 문제

* 기준 금액 설정

  * 원가와 정가의 구체적인 금액 없이 이익률이나 할인율 등 비율 조건만 주어진 경우, 원가를 100원 또는 1,000원으로 두면 계산하기 쉽다.

  * 구하려는 값이 할인율이나 이익률처럼 비율인 경우에 활용한다. 실제 금액이 조건으로 주어졌다면 그 조건도 반영해야 한다.

* 예시

  * 원가에 30%의 이익을 붙여 정가를 정한 뒤, 정가에서 10% 할인하여 판매했을 때 원가 대비 이익률을 구하는 경우

  ```
  원가 = 100원
  정가 = 100 × 1.3 = 130원
  판매가 = 130 × 0.9 = 117원
  이익 = 117 - 100 = 17원
  이익률 = 17 ÷ 100 × 100 = 17%
  ```

## 자료해석(1)

### 진위 여부 판단

* 선지 판단 순서

  * 선지를 1번부터 차례대로 판단하기보다, 계산이 필요 없거나 간단한 계산으로 판단할 수 있는 선지부터 확인한다.

  * 복잡한 계산이 필요한 선지는 뒤로 미루어 풀이 시간을 줄인다.

* 선지 예시(5)

  * ① A 지점의 방문객 수는 전년 대비 15% 증가했다.

  * ② 올해 전체 방문객 수는 전년도보다 5% 이상 증가했다.

  * ③ 올해 방문객 수는 A 지점이 가장 많다.

  * ④ B 지점의 방문객 수는 전년도보다 1,170명 많다.

  * ⑤ C 지점의 방문객 수는 전년도보다 적다.

* 예시의 판단 순서

  * 기본 순서: ⑤ → ③ → ④ → ① → ②

  * ⑤: C 지점의 전년도와 올해 수치 두 개만 비교하면 되므로 먼저 확인한다.

  * ③: 올해 각 지점의 수치를 비교해 최댓값을 찾는다.

  * ④: B 지점의 올해 수치에서 전년도 수치를 빼면 된다.

  * ①: A 지점의 증가 인원과 전년도 수치를 이용해 증가율을 확인해야 한다.

  * ②: 전년도와 올해의 전체 합계를 각각 구한 뒤 증가율까지 확인해야 하므로 마지막으로 미룬다.

  * 실제 자료에서 수치가 단순하거나 정렬되어 있다면 더 쉽게 판단할 수 있는 선지부터 확인한다.
