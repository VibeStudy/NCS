## 응용 수리(3)

### 능률 문제

* 수식을 세우는 방법

  ```
  A 혼자서는 6시간이 걸린다.

  → x = 1/6

  A와 B가 함께는 3시간이 걸린다

  → x+y = 1/3. y = 1/6

  이 때 x는 A가 한 시간동안 처리하는 일의 양.
  y는 B가 한 시간동안 처리하는 일의 양을 의미한다.
  ```

* 계산하기 쉬운 수식으로 변환

  ```
  A는 2시간, B는 1시간 18분이 걸린다.

  → 시간을 분으로 변환
  → A는 1/120, B는 1/78
  ```

### 의자에 앉는 문제

* 변수: 의자 수

  ```
  의자에 6명씩 앉았을 때 10명이 남는다. (중략) 참석 인원은 몇 명인가?

  → 의자 수를 x, 참석 인원을 y로 둔다.
  → y = 6x + 10
  ```

* 마지막 의자에 앉은 인원이 주어지지 않은 경우는 부등식

  ```
  의자에 7명씩 앉았을 때 의자 1개가 남는다.

  마지막으로 사용한 의자에 앉은 인원이 주어지지 않았으므로 부등식을 세운다.

  7(x - 2) + 1 ≤ y ≤ 7(x - 2) + 7
  = 7x - 13 ≤ y ≤ 7x - 7

  빈 의자 1개와 마지막으로 사용한 의자 1개를 제외한 x - 2개 의자에는 각각 7명씩 앉는다.
  마지막으로 사용한 의자에는 1명 이상 7명 이하가 앉을 수 있다.
  ```

### 기초통계(2)

* 대표값(3)

  * 평균

    * 모든 자료의 합을 자료 수로 나눈 값

    ```
    평균 = 자료의 합 ÷ 자료 수
    ```

    * 모든 자료를 반영하지만, 극단값의 영향을 크게 받음

  * 중앙값

    * 자료를 크기순으로 정렬했을 때 가운데에 위치한 값

    ```
    홀수 개: 가운데 값
    짝수 개: 가운데 두 값의 평균
    ```

    * 극단값의 영향이 작음

  * 최빈값

    * 가장 자주 나타나는 값
    * 최빈값이 없거나 여러 개일 수 있음

* 산포도(2)

  * 분산

    * 자료가 평균에서 얼마나 퍼져 있는지 나타내는 값

    ```
    분산 = (각 자료와 평균의 차이를 제곱한 값의 합) ÷ 자료 수
    ```

    * 편차를 제곱하므로 항상 0 이상
    * 분산이 클수록 자료의 흩어진 정도가 큼

  * 표준편차

    * 분산의 양의 제곱근

    ```
    표준편차 = √분산
    ```

    * 원래 자료와 같은 단위를 사용하므로 분산보다 해석하기 쉬움
    * 표준편차가 작을수록 평균 주변에 자료가 모여 있음
