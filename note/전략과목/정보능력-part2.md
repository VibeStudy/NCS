### Excel 함수식

* IF: 조건이 참이면 값1, 거짓이면 값2 반환 → `=IF(조건, 값1, 값2)`
* COUNT: 숫자가 있는 셀 개수 → `=COUNT(범위)`
* COUNTA: 비어있지 않은 셀 개수(문자 포함) → `=COUNTA(범위)`
* COUNTIF: 단일 조건을 만족하는 셀 개수 → `=COUNTIF(범위, 조건)`
* COUNTIFS: 여러 조건을 모두 만족하는 셀 개수 → `=COUNTIFS(범위1, 조건1, 범위2, 조건2, ...)`
* SUM: 합계 → `=SUM(범위)`
* SUMIF: 단일 조건을 만족하는 셀들의 합계 → `=SUMIF(조건범위, 조건, 합계범위)`
* SUMIFS: 여러 조건을 모두 만족하는 셀들의 합계 → `=SUMIFS(합계범위, 조건범위1, 조건1, 조건범위2, 조건2, ...)`
* AVERAGE: 평균(숫자만) → `=AVERAGE(범위)`
* AVERAGEA: 평균(문자는 0으로 처리) → `=AVERAGEA(범위)`
* AVERAGEIF: 단일 조건을 만족하는 셀들의 평균 → `=AVERAGEIF(조건범위, 조건, 평균범위)`
* AVERAGEIFS: 여러 조건을 모두 만족하는 셀들의 평균 → `=AVERAGEIFS(평균범위, 조건범위1, 조건1, 조건범위2, 조건2, ...)`
* ROUND: 지정한 자릿수로 반올림 → `=ROUND(수, 자릿수)` (양수=소수점 아래, 음수=정수 자리)
* MOD: 나눗셈의 나머지 반환 → `=MOD(수, 나누는수)`
* MAX: 최댓값 → `=MAX(범위)`
* MIN: 최솟값 → `=MIN(범위)`
* MODE: 범위에서 가장 자주 나타나는 값 반환 → `=MODE(범위)`
* LARGE: k번째로 큰 값 → `=LARGE(범위, k)`
* SMALL: k번째로 작은 값 → `=SMALL(범위, k)`
* TODAY: 오늘 날짜 반환 → `=TODAY()`
* NOW: 현재 날짜와 시간 반환 → `=NOW()`
* YEAR: 날짜에서 연도 추출 → `=YEAR(날짜)`
* MONTH: 날짜에서 월 추출 → `=MONTH(날짜)`
* DAY: 날짜에서 일 추출 → `=DAY(날짜)`
* DATE: 연·월·일을 날짜로 변환 → `=DATE(연, 월, 일)`
* WEEKDAY: 날짜에 해당하는 요일 번호 반환 → `=WEEKDAY(날짜, [반환유형])` (반환유형 1=일요일 1, 월요일 2 / 2=월요일 1, 일요일 7)
* DAYS: 두 날짜 사이의 일수 반환 → `=DAYS(종료일, 시작일)`
* TRIM: 문자열의 불필요한 공백 제거 → `=TRIM(문자열)`
* SEARCH: 문자열에서 찾을 문자의 시작 위치 반환 → `=SEARCH(찾을문자, 문자열, [시작위치])` (대소문자 구분 안 함)
* PROPER: 각 단어의 첫 글자를 대문자로 변환 → `=PROPER(문자열)`
* LOWER: 문자열을 소문자로 변환 → `=LOWER(문자열)`
* REPLACE: 문자열의 특정 위치부터 n개 문자를 다른 문자로 교체 → `=REPLACE(원본, 시작위치, 문자수, 새문자)`
* VLOOKUP: 열 기준 세로 방향 검색 → `=VLOOKUP(찾을값, 표범위, 열번호, [유사일치])` (유사일치: TRUE=근사값, FALSE=정확히)
* HLOOKUP: 행 기준 가로 방향 검색 → `=HLOOKUP(찾을값, 표범위, 행번호, [유사일치])`
* RIGHT: 오른쪽에서 n개 문자 추출 → `=RIGHT(문자열, n)`
* MID: 지정 위치부터 n개 문자 추출 → `=MID(문자열, 시작위치, n)`
* LEFT: 왼쪽에서 n개 문자 추출 → `=LEFT(문자열, n)`
* RANK: 순위 반환 → `=RANK(값, 범위, [순서])` (순서: 0=내림차순, 1=오름차순)
* MATCH: 범위에서 찾을 값의 상대 위치 반환 → `=MATCH(찾을값, 범위, [일치유형])` (일치유형: 0=정확히, 1=작거나 같은 최댓값, -1=크거나 같은 최솟값)
* INDEX: 범위에서 지정한 행·열 위치의 값 반환 → `=INDEX(범위, 행번호, 열번호)`
* OFFSET: 기준 셀에서 지정한 행·열만큼 떨어진 위치의 참조 범위 반환 → `=OFFSET(기준셀, 행수, 열수, [높이], [너비])`
* DSUM: 데이터베이스에서 조건을 만족하는 필드의 합계 → `=DSUM(데이터베이스, 필드, 조건범위)`
* DCOUNT: 데이터베이스에서 조건을 만족하는 숫자 셀 개수 → `=DCOUNT(데이터베이스, 필드, 조건범위)`
* CORREL: 두 데이터 범위의 상관계수(-1~1) 반환 → `=CORREL(범위1, 범위2)`

### 문서 작성 용어

* 미주: 본문에서 보충 설명이나 출처가 필요한 부분을 표시하고, 해당 설명을 문서나 장의 끝에 모아 적는 주석

* 머리글/바닥글: 문서의 각 쪽 위쪽 또는 아래쪽에 반복해서 표시되는 영역
    * 제목, 작성자, 쪽 번호, 날짜 등을 넣을 때 사용함

* 색인: 문서의 주요 용어나 주제를 찾아보기 쉽게 정리한 목록
    * 색인어와 해당 내용이 있는 쪽 번호 또는 위치 정보로 구성됨

* 각주: 본문에서 보충 설명이나 출처가 필요한 부분을 표시하고, 같은 쪽 아래쪽에 적는 주석

### 한글 단축키

* 서식메뉴 
    * alt + l: 글자 모양 설정 창 열기
    * alt + t: 문단 모양 설정 창 열기
    * alt + k, n: 문단 번호 또는 글머리표 설정 창 열기
    * f6: 스타일 목록으로 이동
    * ctrl + shift + insert: 문단 번호 속성 넣기 또는 빼기
    * ctrl + 숫자: 해당 번호의 스타일 적용
    * ctrl + ]: 글자 크기 1pt 크게
    * ctrl + [: 글자 크기 1pt 작게
    * alt + shift + w: 글자 사이 간격 넓히기
    * alt + shift + n: 글자 사이 간격 좁히기
    * alt + shift + j: 글자 폭 좁히기
    * alt + shift + k: 글자 폭 넓히기
    * alt + shift + u: 밑줄 적용 또는 해제
    * alt + shift + b: 굵게 적용 또는 해제
    * alt + shift + i: 기울임 적용 또는 해제
* 편집메뉴
    * ctrl + z: 실행 취소
    * ctrl + shift + z: 취소한 작업 다시 실행
    * ctrl + x: 선택한 내용 잘라내기
    * ctrl + c: 선택한 내용 복사
    * ctrl + v: 붙여넣기
    * ctrl + alt + v: 붙여넣기 방식 선택
    * 커서 두고 alt + c: 현재 위치의 모양 복사
    * 블록 상태 alt + c: 복사한 모양을 선택 영역에 적용
    * ctrl + e: 선택한 내용 지우기
    * ctrl + a: 문서 전체 선택
    * f3: 선택 영역 지정 시작
* 쪽메뉴
    * f7: 편집 용지 설정 창 열기
    * ctrl + n + h: 머리말 또는 꼬리말 넣기
    * ctrl + n + p: 쪽 번호 넣기
    * ctrl + n + s: 감추기 설정
    * ctrl + n + g: 구역 설정 창 열기
    * ctrl + enter: 새 쪽으로 나누기
    * ctrl + shift + enter: 새 단으로 나누기
    * ctrl + alt + enter: 다단 설정을 나누기
    * alt + shift + enter: 새 구역으로 나누기
* 파일메뉴
    * alt + n: 새 문서 만들기
    * ctrl + alt + n: 문서마당 열기
    * alt + o: 문서 불러오기
    * alt + f3: 최근 작업 문서 열기
    * alt + s: 저장
    * ctrl + s: 저장
    * alt + v: 다른 이름으로 저장
    * alt + p: 인쇄 창 열기
    * ctrl + p: 인쇄
    * alt + x: 한글 종료
    * ctrl + f4: 현재 문서 닫기
    * f7: 편집 용지 설정 창 열기

## 전자금융사기(0)

* 랜섬웨어: 암호화한 데이터를 인질 삼아 금품을 요구하는 공격 
* 피싱: 금융기관 등을 사칭한 이메일이나 웹사이트로 정보를 탈취하는 공격 
* 스미싱: 문제메시지를 이용한 피싱 공격으로, 링크 클릭을 유도해 정보를 탈취하는 공격 
* 파밍: 가짜 사이트로 유인해 정보를 탈취하는 공격 
* 스푸핑: 적극적 공격, 악의적으로 다른 사람이나 시스템을 속여 정보를 탈취하는 공격 
* 스니핑: 소극적 공격, 네트워크 패킷을 가로채어 정보를 탈취하는 공격 
* 메모리해킹: 피해자 PC 메모리에 상주하는 데이터를 위변조하는 공격
